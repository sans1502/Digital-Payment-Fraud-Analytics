Digital Payment Fraud Analytics Dashboard

Project Overview
This Power BI dashboard analyzes digital payment transactions to identify fraud patterns 
and transaction trends.

Dataset
- Total Transactions: 200,000
- Fraud Transactions: 268
- Fraud Percentage: 0.13%

Dashboard Features
- KPI Cards
- Fraud by Transaction Type
- Transaction Type Distribution
- Amount by Transaction Type
- Interactive Slicer

Tools Used
- Power BI
- Power Query
- DAX

Key Insights
- Transfer transactions have the highest fraud cases.
- Cash Out is the second highest fraud transaction type.
- Fraud rate is only 0.13%.
