# Digital Payment Fraud & Scam Pattern Analytics

## About the Project

This project was created to analyze digital payment transactions and understand fraud patterns using Python, SQL, and Power BI. The main objective was to perform data analysis, identify fraudulent transactions, and build an interactive dashboard that provides meaningful insights from the dataset.

The project covers the complete workflow, including data exploration, data cleaning, SQL analysis, and dashboard development.

---

## Dataset

- Total Transactions: 200,000+
- Fraud Transactions: 268
- Fraud Percentage: 0.13%

---

## Tools & Technologies

- Python
- SQL
- Power BI
- Power Query
- DAX
- Jupyter Notebook

---

## Dashboard Includes

- Total Transactions
- Total Fraud Transactions
- Fraud Percentage
- Fraud by Transaction Type
- Transaction Type Distribution
- Transaction Amount by Type
- Fraud vs Non-Fraud Comparison
- Transaction Type Filter (Slicer)

---

## Key Findings

- Most fraud cases are found in **TRANSFER** transactions.
- **CASH_OUT** is the second most common fraud transaction type.
- Fraud accounts for only **0.13%** of all transactions in the dataset.
- The dashboard makes it easy to compare fraud trends across different transaction types.
